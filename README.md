# Analysis of NBA Player Efficiency (PER) Using Multiple Regression

## Summary

2025 spring semester Econometrics course project examines NBA Player Efficiency Rating (PER) using regression, transformations, dummy variables (position indicators), heteroskedasticity tests, and weighted least squares.
This report was prepared as coursework and has not been submitted outside the course.

## Folder description

- [`original-korean`](original-korean/) contains the Korean report and the original notebooks, with data and a duplicated reproduction folder removed from this public copy. The notebooks retain analysis results from their original runs and some individual player data in their saved outputs.
- [`english-report`](<english-report/Analysis of Player Efficiency (PER).pdf>) contains an English translation of the original Korean report
- [`reproduction`] contains the figure reproduction code and previously generated figures. See its [README](reproduction/README.md) for the required inputs, columns, placement, and execution.
